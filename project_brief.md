# My agent: weather-agent
One-liner: A conversational agent that helps travelers and city explorers check current weather and look up city conditions, attractions, and local recommendations.

Tool coverage:
- Memory: User's home city, favorite travel destinations, preferred temperature units (Celsius/Fahrenheit), and packing preferences.
- Tools: Weather lookups, current local time, Firestore queries to search cities catalog, add new city records, and log weather reports.
- Catalog/UI: Catalog of cities with current climate, best travel season, popular tags, and weather notes.
- Image gen: Visual destination postcards / weather scene images.
- Sandbox: Temperature unit conversions, packing checklist analysis.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Firestore city catalog, Vertex AI Memory Bank, Cloud Run frontend
